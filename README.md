# CastTheDice

Ett litet tärningsspel i konsolen, skrivet i C# när jag började lära mig språket.

Spelet kastar två tärningar. Blir summan 12 vinner du, annars får du frågan om du vill kasta igen.

## Köra

    dotnet run

## Vad jag övade på

- `while`-loop med `break`
- `for`-loop och `Thread.Sleep` för de tre punkterna innan resultatet
- `Random.Next(1, 7)` för ett tal mellan 1 och 6
- `Console.ReadLine` och en `if`-sats för svaret
- `Console.ForegroundColor` för grön text när man vinner
